# 📱 Unioz Mobile – Aplicativo Universitário

![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)
![Android](https://img.shields.io/badge/android-%233DDC84.svg?style=for-the-badge&logo=android&logoColor=white)
![SQL Server](https://img.shields.io/badge/sql%20server-%23CC2927.svg?style=for-the-badge&logo=microsoftsqlserver&logoColor=white)

O **Unioz Mobile** é um aplicativo Android desenvolvido em **Java (Android Studio)** com interface construída em **XML** e integração direta com **Microsoft SQL Server**.

O projeto simula um sistema acadêmico universitário, aplicando conceitos de desenvolvimento mobile nativo, organização modular e integração com banco de dados relacional.

---

## 🚀 Funcionalidades

- 🔐 Sistema de autenticação
- 👤 Visualização de perfil do aluno
- 📢 Consulta de avisos e informações acadêmicas
- 📋 Listagem de dados vindos do SQL Server
- 🔄 Integração Android ↔ Banco Relacional

---

## 🛠️ Tecnologias Utilizadas

- **Java (Android Nativo)**
- **XML (Layouts e Interface)**
- **Android Studio**
- **SQL Server Management Studio (SSMS)**
- **Git & GitHub**

---

## 🏗️ Estrutura e Arquitetura

Separação por responsabilidades:

- **Activities** → Controle das telas  
- **XML Layouts** → Estrutura visual da interface  
- **Models** → Representação das entidades do banco  
- **Classe de Conexão** → Comunicação com SQL Server  
- **Adapters** → Integração com listas (RecyclerView/ListView)
